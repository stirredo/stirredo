# Abhi G

Senior software engineer. Distributed systems and machine learning infrastructure.

I began writing software professionally in 2016 and have spent most of the decade since on
the problems that appear when one machine is no longer sufficient: event pipelines,
caches, search clusters, and the services that depend on them staying available.

Machine learning brought the same problems in a different form. Training a model is a
well-understood process; serving it to a large number of users, keeping it fast under
load, and releasing new versions without disruption is where most of the engineering
effort lies. That is the area I work in.

My current focus is inference for models: serving them at scale without
idle accelerator capacity, sharing hardware between production and research workloads,
and deploying new models safely.
